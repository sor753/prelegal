# デザインパートナー契約

1. <span class="header_2">デザインパートナー概要</span>
    1. <span class="header_3">製品へのアクセス。</span>  <span class="keyterms_link">パートナー</span>は、製品の最初のユーザーの一人となることを希望します。<span class="keyterms_link">期間</span>中、<span class="keyterms_link">パートナー</span>は、内部ビジネス目的、<span class="keyterms_link">プロバイダー</span>へのフィードバック提供、および<span class="keyterms_link">プログラム</span>への参加のために、製品への早期アクセスが与えられます。ただし、<span class="keyterms_link">パートナー</span>がこの契約の条件を遵守することが前提となります。
    2. <span class="header_3">プログラムおよびフィードバック。</span>  <span class="keyterms_link">プログラム</span>の目的は、<span class="keyterms_link">プロバイダー</span>のすべての顧客またはユーザーが一般利用できるように製品を開発・構築・改善することです。<span class="keyterms_link">パートナー</span>は相互に合意されたスケジュールで<span class="keyterms_link">プロバイダー</span>にフィードバックを提供し、<span class="keyterms_link">プログラム</span>に参加します。
    3. <span class="header_3">製品改善。</span>  <span class="keyterms_link">プロバイダー</span>は製品を開発・改善し、<span class="keyterms_link">プログラム</span>からの全てのフィードバックおよび製品に関する洞察を、制限または義務なく自由に使用することができます。<span class="keyterms_link">パートナー</span>は、<span class="keyterms_link">プロバイダー</span>がこのような形で使用できないフィードバック、または本目的のためのフィードバックを提供しないものとします。
2. <span class="header_2">費用および経費</span>
    1. <span class="keyterms_link">パートナー</span>は<span class="keyterms_link">プロバイダー</span>に<span class="keyterms_link">料金</span>（ある場合）を支払います。
3. <span class="header_2">期間および終了</span>
    1. <span class="header_3">契約期間。</span>  この契約は<span class="keyterms_link">発効日</span>に開始し、<span class="keyterms_link">期間</span>の間継続します。<span class="keyterms_link">プロバイダー</span>と<span class="keyterms_link">パートナー</span>はメールによる連絡を含め、相互に合意して<span class="keyterms_link">期間</span>を延長することができます。
    2. <span class="header_3">終了。</span>  いずれかの当事者は、理由の有無にかかわらずこの契約を終了することができます。この契約を終了するには、終了する当事者は相手方に30日前の事前通知を行わなければなりません。
    3. <span class="header_3">終了の効果。</span>  契約の失効または終了時に：
        a. <span class="keyterms_link">パートナー</span>は製品へのアクセスまたは使用の権利を失います。<span class="keyterms_link">パートナー</span>は契約の下でフィードバックを提供したり<span class="keyterms_link">プログラム</span>に参加する義務を負いません。
        b. 各受領者は、その所有または管理下にある開示者の機密情報を返還または破棄します。
    4. <span class="header_3">存続条項。</span>
        a. 以下の条項は契約の失効または終了後も存続します：第1.3条（製品改善）、第3.3条（終了の効果）、第3.4条（存続条項）、第4条（保証の免責）、第5条（機密保持）、第6条（知的財産）、第7条（一般条項）、第8条（定義）、およびこれらの条項が参照する表紙の部分。
        b. 各受領者は、通常の事業過程で維持される標準的なバックアップまたは記録保持方針に従って、または適用法により要求される場合、開示者の機密情報を保持することができます。この場合、第5条（機密保持）は保持された機密情報に引き続き適用されます。
4. <span class="header_2">保証の免責</span>
    1. <span class="keyterms_link">プロバイダー</span>および<span class="keyterms_link">パートナー</span>は、商品性、特定目的適合性、権原、非侵害の黙示保証を含む、明示または黙示のすべての保証を免責します。これらの免責は適用法により許可される最大限の範囲で適用されます。
5. <span class="header_2">機密保持</span>
    1. <span class="header_3">不使用および不開示。</span>  契約において別途承認されない限り、受領者は（a）この契約の下での義務の履行または権利の行使のためにのみ開示者の機密情報を使用し；（b）開示者の機密情報を他者に開示しないものとします。また、受領者は、自社の類似情報に対して使用する保護と少なくとも同等の保護を用いて開示者の機密情報を保護しますが、合理的な注意基準を下回ってはなりません。
    2. <span class="header_3">例外。</span>  機密情報には、（a）開示者による開示前に受領者が機密保持義務なく知っていた情報；（b）受領者の過失によらず公に知られ一般に利用可能になった情報；（c）開示を行う権限を有する者から機密保持義務なく受領した情報；（d）開示者の機密情報を使用または参照することなく受領者が独立して開発した情報は含まれません。また、フィードバックは<span class="keyterms_link">パートナー</span>の機密情報を構成せず、<span class="keyterms_link">プロバイダー</span>は製品を提供するために<span class="keyterms_link">パートナー</span>の機密情報を使用することができます。
    3. <span class="header_3">必要な開示。</span>  受領者は、適用法により要求される範囲で開示者の機密情報を開示することができます。ただし、適用法により禁止されていない限り、受領者は開示者に必要な開示について合理的な事前通知を行い、機密情報の機密扱いの取得に向けた開示者の努力に開示者の費用負担で合理的に協力するものとします。
    4. <span class="header_3">許可される開示。</span>  受領者は、機密情報を知る必要性を有するユーザー、従業員、顧問、請負業者、代表者に開示者の機密情報を開示することができます。ただし、その者または事業体が本第5条と少なくとも同等の機密保持義務に拘束され、受領者が本第5条の条件への全員の遵守について責任を負う場合に限ります。
6. <span class="header_2">知的財産</span>
    1. <span class="header_3">権利の留保。</span>  第1.1条（製品へのアクセス）に規定された製品への限定的アクセスライセンスを除き、<span class="keyterms_link">プロバイダー</span>は製品に対するすべての権利、権原、利益を保持します。これには、フィードバックまたは<span class="keyterms_link">プログラム</span>への<span class="keyterms_link">パートナー</span>の参加に応じて作成された側面、機能、または<span class="keyterms_link">発効日</span>の前後を問わず開発された機能性が含まれます。各開示者は、その機密情報に対するすべての権利、権原、利益を保持します。
    2. <span class="header_3">所有権。</span> <span class="keyterms_link">プロバイダー</span>はすべてのフィードバックを所有します。<span class="keyterms_link">パートナー</span>はフィードバックに対する<span class="keyterms_link">パートナー</span>のすべての権利、権原、利益を<span class="keyterms_link">プロバイダー</span>に譲渡し、<span class="keyterms_link">プロバイダー</span>のフィードバック所有権の確立、証明、または防御に合理的に協力するものとします。
7. <span class="header_2">一般条項</span>
    1. <span class="header_3">完全合意。</span>  この契約はその主題について当事者間の唯一の合意であり、その主題に関する事前または同時期のすべての陳述（書面によるかどうかを問わず）に優先します。
    2. <span class="header_3">変更、分離可能性、放棄。</span>  契約へのいかなる放棄、変更、または変更も書面で行われ、各当事者が署名または電子的に承認しなければなりません。この契約のいずれかの条件が関連する裁判所または統治機関によって無効または執行不能と判断された場合、この契約の残りの条件は引き続き完全に効力を有します。ある当事者が条件、オプション、または権利を執行しないことは、その当事者による条件、オプション、または権利の放棄を構成しません。
    3. <span class="header_3">準拠法および選択された裁判所。</span>  <span class="keyterms_link">準拠法</span>は、抵触法規定を考慮せず、この契約に関するすべての解釈および紛争を規律します。当事者は、この契約に関する訴訟、訴え、または手続きを<span class="keyterms_link">選択された裁判所</span>に提起し、各当事者は<span class="keyterms_link">選択された裁判所</span>の専属的管轄に取消不能的に服するものとします。
    4. <span class="header_3">差止救済。</span>  第7.3条（準拠法および選択された裁判所）にかかわらず、第5条（機密保持）の違反または当事者の知的財産権の侵害は、金銭的損害では適切に補償できない回復不能な損害を引き起こす場合があります。その結果、第5条（機密保持）の実際のまたは脅迫による違反、または当事者の知的財産権の侵害が発生した場合、違反していない当事者または侵害されていない当事者は、供託金なしに、その他の権利または救済手段を制限することなく、権限ある裁判所において差止命令を含む適切な衡平法上の救済を求めることができます。
    5. <span class="header_3">制限。</span>  この契約により明示的に許可された場合を除き、<span class="keyterms_link">パートナー</span>は（他者にも）以下のことを行いません：（a）製品のソースコードまたは基礎となるアイデアやアルゴリズムをリバースエンジニアリング、デコンパイル、または発見しようとすること（適用法がこの制限を禁止する範囲を除く）；（b）製品へのアクセスまたは使用を他者に提供、販売、移転、サブライセンス、貸与、配布、賃貸、またはその他の方法で許可すること；（c）専有の通知またはラベルを削除すること；（d）製品のコピー、変更、または派生物の作成；（e）製品に対するセキュリティまたは脆弱性テストの実施、動作への干渉、性能低下、またはアクセス制限の回避；（f）明示的な許可を有しない製品のアカウント、情報、データ、または部分へのアクセス；（g）競合するサービスまたは製品の開発のための製品の使用；（h）適用法により禁止された活動に製品を使用すること；（i）他者のネットワークまたは機器への不正アクセスのための製品の使用；または（j）適切な権利を有しない情報またはコンテンツを製品に対してアップロード、送信、またはその他の方法で利用可能にすること。
    6. <span class="header_3">非排他的救済手段。</span>  契約が排他的救済手段を定める場合を除き、救済手段を求めまたは行使することは、当事者が利用できる他の権利または救済手段を制限しません。
    7. <span class="header_3">譲渡。</span>  いずれの当事者も、相手方の事前の書面による同意なく、この契約の下でのいかなる権利または義務も譲渡することはできません。ただし、いずれかの当事者は、譲渡する当事者がこの契約に関連するその持分、事業、または資産の全部または実質的に全部の合併、支配権変更、再編、または売却を経る場合、通知により本契約を譲渡することができます。許可されない譲渡の試みは無効です。この契約は、当事者およびその許可された承継人および譲受人を拘束し、その利益のために効力を生じます。
    8. <span class="header_3">通知。</span>  契約に関するいかなる通知、要求、または承認も書面で<span class="keyterms_link">通知先</span>に送付されなければなりません。通知は、（a）メール、書留もしくは認定郵便、または対面配送による確認配送時；または（b）翌日商業配送による郵送後2日後に送達されたものとみなされます。
    9. <span class="header_3">独立請負業者。</span>  当事者は独立請負業者であり、代理人、パートナー、または合弁事業者ではありません。いずれの当事者も、相手方を責任または義務に拘束する権限を有しません。
    10. <span class="header_3">第三者受益者なし。</span>  この契約には第三者受益者はいません。
    11. <span class="header_3">見出しおよび解釈。</span>  条項の見出しは便宜および参照のためのものです。「含む」および類似の表現のすべての使用は非網羅的であり制限なしです。国連国際物品売買条約および統一コンピュータ情報取引法はこの契約には適用されません。
    12. <span class="header_3">署名。</span>  この契約は、電子コピーまたは承認メカニズムによるものを含む副本で署名することができます。各コピーは原本とみなされ、全コピーを合わせると同一の合意となります。
8. <span class="header_2">定義</span>
    1. **「契約」** とは、これらの標準条件、<span class="keyterms_link">プロバイダー</span>と<span class="keyterms_link">パートナー</span>間の表紙、および表紙において参照または添付されているポリシーおよび文書を意味します。
    2. **「適用法」** とは、<span class="keyterms_link">プロバイダー</span>または<span class="keyterms_link">パートナー</span>に適用されまたは規律する、関連する政府当局の法律、規則、規制、裁判所命令、その他の拘束力ある要件を意味します。
    3. **「機密情報」** とは、この契約に関連して<span class="keyterms_link">発効日</span>以前を含め、開示者またはその代理人により受領者に開示されたあらゆる形式の情報を意味します。この情報は（a）開示者が「機密」、「専有」等と識別したもの；または（b）その性質および開示の状況から機密または専有として合理的に理解されるべきものです。機密情報には、この契約の存在および各表紙上の情報が含まれます。<span class="keyterms_link">プロバイダー</span>の機密情報には製品に関する非公開情報が含まれます。
    4. **「表紙」** とは、標準条件を組み込み<span class="keyterms_link">プロバイダー</span>と<span class="keyterms_link">パートナー</span>を識別する当事者が署名または電子的に承認した文書を意味します。
    5. **「開示者」** とは、相手方に機密情報を提供または開示する当事者を意味します。
    6. **「フィードバック」** とは、製品または関連サービスに関する提案、フィードバック、またはコメントを意味します。
    7. **「製品」** とは、表紙に記載された製品またはサービスを意味します。
    8. **「受領者」** とは、相手方から機密情報を受領する当事者を意味します。
