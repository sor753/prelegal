# サービスレベル契約

1. <span class="header_2" id="1">稼働率</span>
    1. <span class="header_3" id="1.1">目標稼働率。</span>  <span class="orderform_link">目標稼働率</span>が存在する場合、<span class="coverpage_link">プロバイダー</span>は各暦月で計算された<span class="orderform_link">目標稼働率</span>以上のクラウドサービスの可用性を確保するために商業的に合理的な努力を行います。
    2. <span class="header_3" id="1.2">稼働率の計算。</span>  <span class="coverpage_link">プロバイダー</span>と<span class="coverpage_link">顧客</span>は、クラウドサービスの可用性を、暦月に測定した総利用可能時間数からダウンタイム時間数を差し引き、総利用可能時間数で割ったものとして計算することに合意します。<span class="orderform_link">サブスクリプション期間</span>が月の一部のみを含む場合、分子と分母には当該月の<span class="orderform_link">サブスクリプション期間</span>に含まれる日のみが含まれます。

2. <span class="header_2" id="2">応答時間</span>
    1. <span class="header_3" id="2.1">目標応答時間。</span> <span class="orderform_link">目標応答時間</span>が存在する場合、<span class="coverpage_link">プロバイダー</span>は<span class="orderform_link">サポートチャンネル</span>に送信されたサポートリクエストに<span class="orderform_link">目標応答時間</span>内に応答するために商業的に合理的な努力を行います。
    2. <span class="header_3" id="2.2">応答時間の計算。</span>  <span class="coverpage_link">プロバイダー</span>と<span class="coverpage_link">顧客</span>は、<span class="coverpage_link">プロバイダー</span>の応答時間を、<span class="coverpage_link">顧客</span>が<span class="orderform_link">サポートチャンネル</span>にサポートリクエストを送信した時点から<span class="coverpage_link">プロバイダー</span>またはその担当者がリクエストを具体的に確認した時点までの総時間として計算することに合意します。自動応答はこのSLAの目的においては具体的な確認とはみなされません。

3. <span class="header_2" id="3">救済措置</span>
    1. <span class="header_3" id="3.1">サービスクレジット。</span>  <span class="orderform_link">目標稼働率</span>が存在し、クラウドサービスの可用性が<span class="orderform_link">目標稼働率</span>を下回った場合、<span class="coverpage_link">顧客</span>は<span class="orderform_link">稼働率クレジット</span>を受け取る権利を有します。<span class="orderform_link">目標応答時間</span>が存在し、<span class="coverpage_link">プロバイダー</span>またはそのサポート担当者が<span class="orderform_link">目標応答時間</span>内に<span class="orderform_link">サポートチャンネル</span>に送信されたサポートリクエストを確認しなかった場合、<span class="coverpage_link">顧客</span>は<span class="orderform_link">応答時間クレジット</span>を受け取る権利を有します。サービスクレジットは、<span class="coverpage_link">顧客</span>が<span class="coverpage_link">プロバイダー</span>に対して負う将来のクラウドサービス料金にのみ適用されます。
    2. <span class="header_3" id="3.2">サービスクレジットの請求。</span>  サービスクレジットを受け取るには、<span class="coverpage_link">顧客</span>はサービスクレジットを得たと考える月の終了後7日以内に<span class="coverpage_link">プロバイダー</span>に通知しなければなりません。そうでなければ、その月のサービスクレジット受給資格は失効します。
        a. <span class="orderform_link" id="3.2.a">稼働率クレジット</span>については、<span class="coverpage_link">顧客</span>はクラウドサービスにアクセスできなかった時期に関する情報を含めなければなりません。<span class="coverpage_link">顧客</span>はクラウドサービスへのアクセス試行に関する追加詳細の提供を求められる場合があります。<span class="coverpage_link">プロバイダー</span>が内部監視システムでクラウドサービスの利用不能を確認でき、その障害が除外時間または<span class="orderform_link">予定されたダウンタイム</span>に該当しない場合、<span class="coverpage_link">プロバイダー</span>は該当する<span class="orderform_link">稼働率クレジット</span>を計算し、将来の請求書に適用するための<span class="coverpage_link">顧客</span>のアカウントに発行します。
        b. <span class="orderform_link" id="3.2.b">応答時間クレジット</span>については、<span class="coverpage_link">顧客</span>は<span class="coverpage_link">プロバイダー</span>へのコンタクト時期と方法に関する情報を含めなければなりません。<span class="coverpage_link">顧客</span>は関連するインシデントおよびサポートを受けるための試行に関する追加詳細の提供を求められる場合があります。<span class="coverpage_link">プロバイダー</span>が<span class="coverpage_link">プロバイダー</span>もその担当者も<span class="orderform_link">目標応答時間</span>内に<span class="coverpage_link">顧客</span>のサポートリクエストに応答しなかったことを確認できる場合、<span class="coverpage_link">プロバイダー</span>は該当する<span class="orderform_link">応答時間クレジット</span>を計算し、将来の請求書に適用するための<span class="coverpage_link">顧客</span>のアカウントに発行します。
    3. <span class="header_3" id="3.3">サービスクレジットの制限。</span>  サービスクレジットは金銭的金額に交換または換算することはできません。サービスクレジットに利息は付きません。サービスクレジットは、単一の<span class="orderform_link">サブスクリプション期間</span>内において、その<span class="orderform_link">サブスクリプション期間</span>のクラウドサービス料金の8%を超えて累積されません。サービスクレジットは該当する注文書が終了すると失効します。
    4. <span class="header_3" id="3.4">終了。</span>  クラウドサービスが連続する3ヶ月のうち2ヶ月の<span class="orderform_link">目標稼働率</span>を達成せず、<span class="coverpage_link">顧客</span>が影響を受けた各月の終了後7日以内に<span class="coverpage_link">プロバイダー</span>に通知した場合、<span class="coverpage_link">顧客</span>は<span class="coverpage_link">プロバイダー</span>への書面による通知により、影響を受けた注文書を直ちに終了することができます。<span class="coverpage_link">顧客</span>が本条に基づいて注文書を終了した場合、<span class="coverpage_link">プロバイダー</span>は<span class="orderform_link">サブスクリプション期間</span>の残余期間の前払い料金を日割りで返金します。
    5. <span class="header_3" id="3.5">排他的救済手段。</span>  このSLAは、クラウドサービスが<span class="orderform_link">目標稼働率</span>を達成できないことおよび<span class="orderform_link">目標応答時間</span>を達成できないことに対する<span class="coverpage_link">顧客</span>の排他的救済手段および<span class="coverpage_link">プロバイダー</span>の全責任を定めます。

4. <span class="header_2" id="4">定義</span>
    1. <span id="4.1">**「利用可能時間」**</span>  とは、暦月の総時間数から除外時間および<span class="orderform_link">予定されたダウンタイム</span>を差し引いたものを意味します。
    2. <span id="4.2">**「ダウンタイム時間」**</span> とは、<span class="coverpage_link">プロバイダー</span>の内部監視システムで確認された通り、クラウドサービスが<span class="coverpage_link">顧客</span>に利用できない暦月の総時間数から除外時間および<span class="orderform_link">予定されたダウンタイム</span>を差し引いたものを意味します。
    3. <span id="4.3">**「除外時間」**</span> とは、クラウドサービスが以下の理由で利用できない場合を意味します：（a）不可抗力事由；（b）一般的なインターネット接続の問題；（c）<span class="coverpage_link">プロバイダー</span>以外の者が提供し<span class="coverpage_link">プロバイダー</span>の合理的な管理の範囲外の機器またはソフトウェア；または（d）契約により承認されていない方法での<span class="coverpage_link">顧客</span>によるクラウドサービスの使用。
    4. <span id="4.4">**「サービスクレジット」**</span> とは、累積した<span class="orderform_link">稼働率クレジット</span>と累積した<span class="orderform_link">応答時間クレジット</span>の合計を意味します。
    5. <span id="4.5">**「SLA」**</span> とは、該当する注文書に組み込まれたこれらのSLA標準条件を意味します。
    6. <span id="4.6">**「SLA標準条件」**</span> とは、<https://commonpaper.com/standards/service-level-agreement/2.0/>に掲載されているCommon Paper サービスレベル契約 標準条件 バージョン2.0を意味します。
